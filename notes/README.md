# Notes

Generated notes, audits, and reports produced while working in this repository.
Each file captures a point in time and is not kept up to date after it is written.


## Contents

* [2026-08-08-ci-audit.md][] - audit of every CI and automation file, with each pinned version checked against an authoritative source.


## Naming and scope

* Name a file `<YYYY-MM-DD>-<slug>.md`, using `lowercase-with-dashes`, where the date is the day the note was written.
* Open the note with an H1 that repeats the title and the date, then a short summary section.
* Keep repository documentation in `docs/` and reusable prompt files in `prompts/`. See [docs/README.md][] and [prompts/README.md][].
* Update the index above whenever a note is added, removed, or renamed.
